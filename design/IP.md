# WorkGuy 视觉 IP 规范 v1

> 这不是一份"配色表"，是 WorkGuy 这个角色长什么样、怎么动、怎么说话的定义。
> 所有 TUI 动效必须回到这份文档来对齐。

---

## 一、角色定位

**WorkGuy —— 你的工作搭子。**

不是一个冷冰冰的终端工具，是一个**坐在你旁边干活的伙伴**。性格设定：

- **可靠**：干活利落，不废话，不邀功
- **专注**：忙起来会"进入状态"（有专门的动效表达）
- **有点呆萌**：不完美，会思考、会卡壳、会眼睛打转——这让它像个"人"而不是"程序"
- **不谄媚**：不用"太棒了！""好问题！"这类话。干活的人不这样说话

对标参照：不是 Clippy 那种打扰人的助手，是那种你专心干活时安静待在旁边、需要时立刻回应的搭档。

## 二、形象：Guy

**方头机器人。** 头是一块屏幕（因为它是终端里的东西），身体极简。

```
      ▄▄▄▄▄▄▄▄▄▄▄▄
     █  ▄▄    ▄▄  █
     █  ██    ██  █        ← 眼睛（屏幕上的光点）
     █            █
     █   ▄▀▀▀▀▄   █        ← 嘴（一条简线）
     █  ▀      ▀  █
      ▀▀▀▀▀▀▀▀▀▀▀▀
```

**为什么是方头**：圆形头在终端字符里做不干净，方块既贴合字符网格，也符合"屏幕里的打工人"这个设定。

### 表情系统（Guy 会变脸，这是 IP 的核心）

| 表情 | 触发时机 | 形态 |
|---|---|---|
| 待机 | 等待输入 | 双眼常亮，表情平静 |
| 思考 | 模型推理中 | **双眼转圈** + 嘴部省略号 |
| 干活 | 执行工具 | 单眼变方块（专注），身体有脉冲 |
| 完成 | 任务成功 | 双眼变弯月 `⌒⌒`，嘴角上扬 |
| 卡住 | 出错/被拒 | 双眼变叉 `××`，身体下沉一格 |

**这套表情是 WorkGuy 的招牌。** 别的终端工具只有 spinner，我们有脸。

## 三、色彩系统

**主色：青蓝（Cyan）** —— 理性、专业、屏幕感
**辅色：琥珀（Amber）** —— 温度、人类感，用于强调与提示
**语义色**：成功绿 / 警告黄 / 错误红

| 语义 | 256 色 | 用途 |
|---|---|---|
| `brand` | 51 | Logo、Guy 本体、状态栏边框 |
| `accent` | 208 | 用户输入回显、当前焦点 |
| `dim` | 240 | 次要信息、分隔线、提示栏 |
| `success` | 46 | 完成、审计链完好 |
| `warning` | 214 | 成本告警、上下文压力 |
| `error` | 196 | 拒绝、失败 |

**铁律**：颜色必须**有语义**。不要为了好看而五颜六色——那是玩具，不是工具。

## 四、动效规范

动效不是装饰，是在**替 Guy 表达状态**。三条原则：

1. **状态可读**：用户瞥一眼就知道它在干嘛（思考/干活/完成）
2. **不抢注意力**：动效幅度小、频率低。用户在读内容时，动效不能跳出来干扰
3. **有节奏**：动画帧率稳定，不忽快忽慢

### 动效清单

| 名称 | 位置 | 时长 | 说明 |
|---|---|---|---|
| **开场点亮** | 全屏 | ~600ms | Logo 从中心逐行点亮，Guy 眼睛睁开。**只在启动时出现一次** |
| **思考循环** | 状态栏 | 循环 ~120ms/帧 | 双眼转圈 + 省略号呼吸。这是最常见的动效 |
| **干活脉冲** | 工具调用行 | 循环 | 工具名前的齿轮旋转 |
| **完成一闪** | 回复末尾 | ~200ms | 弯月眼一闪即逝，不驻留 |
| **上下文压力条** | 状态栏右侧 | 实时 | 按 token 占用率渐变绿→黄→红，呼应压缩阈值 |

### 礼仪约束

- **首次启动**才有开场动画；之后启动直接进主界面（人是来干活的，不是来看动画的）
- 用户按任意键**立即跳过**动画
- 动效**绝不阻塞输入**

## 五、语言风格

Guy 怎么说话，也是 IP 的一部分。

| 场合 | ❌ 不要 | ✅ 要 |
|---|---|---|
| 欢迎 | "欢迎使用 WorkGuy！我能帮您做什么呢？" | `在。说吧。` |
| 思考 | "正在努力为您处理中..." | `思考中` |
| 成功 | "任务已成功完成！🎉" | `好了。` |
| 被拒 | "抱歉，您没有权限执行此操作" | `不行，compact 没有工具权限` |
| 出错 | "哎呀，出现了一个小问题~" | `这个挂住了。要重试吗？` |
| 退出 | "感谢使用，祝您生活愉快！" | `走了。` |

**核心**：短、具体、不道歉、不卖萌、不说废话。**像个真正的同事。**

## 七、技术约束

- 动画用**块字符**（`█▀▄▌▐░▒▓`）与 Box Drawing，不用 emoji（终端宽度不可控）
- 所有字符必须**宽度可计算**（交给 `textutil.display_width`）
- 颜色降级：真彩 → 256 色 → 8 色 → 无色。**不能因为终端不支持就崩**
- 动画在**非 TTY 环境**（管道、重定向）自动关闭，退化为纯文本输出
